# ADR Template

Copy this file to `YYYY-MM-DD-short-title.md` in this directory.

```
# ADR-NNNN: <Title>

Date: YYYY-MM-DD · Status: Proposed | Accepted | Superseded by ADR-MMMM

## Context
What forces are at play? What problem, constraints, prior art?

## Decision
What we are doing, stated plainly and affirmatively.

## Alternatives Considered
Options rejected and why.

## Consequences
What becomes easier, what becomes harder, what must now be enforced.
```

ADR-required topics (GOVERNANCE §2): license changes, MVP scope changes, `.ltproj` schema, perf budget trade-offs.
